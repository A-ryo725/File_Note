# PDF保存時の画像圧縮オプション 設計

## 目的
- 「PDFを保存」時に、画像だけを再圧縮して容量を小さくするかどうかを選べるようにする。
- 対象は **元PDF内の画像** と **「写真を追加」で貼った画像** の両方(ユーザー決定)。

## ゴール / 対象外
- ゴール
  - チェックを入れて保存すると、写真・スキャン主体のPDFが目に見えて小さくなる。
  - 文字・図形・フォーム・書き込みはベクターのまま変わらない。
  - チェックなしの保存結果は今までと完全に同じ。
- 対象外
  - 圧縮の強さを選ぶUI(固定値にする)。
  - フォントや本文データの圧縮、ページ全体の画像化。
- 避けること
  - 圧縮で画像が壊れる・色が変わる・透過が消える。
  - 1枚の特殊な画像のせいで保存全体が失敗する。

## 検討した方式
| 方式 | 内容 | 評価 |
|---|---|---|
| A. 画像オブジェクトを個別に差し替え(採用) | pdf-libでPDF内の画像データを1つずつ取り出し、canvasでJPEGに再圧縮して同じ場所に戻す | 画像だけが変わり、文字はそのまま。追加ライブラリ不要 |
| B. ページごと画像化 | pdf.jsでページを描画しJPEGとして貼り直す | 文字が選択・検索できなくなる。「画像だけ」に反するので不採用 |
| C. pdf.jsで画像を復号しpdf-libへ対応付け | 特殊な色形式も扱える | 2つのライブラリ間の対応付けが複雑で壊れやすい。効果の大半はAで得られるので不採用 |

採用はA(実装方式は任されたためClaudeの判断)。

## UI
- ヘッダーの「PDFを保存」ボタンの左にチェックボックス「画像を圧縮」を1つ置く。
- 既定はオフ。PDFを開くまでは無効(保存ボタンと同じ条件)。
- 状態は `localStorage` に記憶する(Claudeの判断)。
- Ctrl+S 保存でもチェック状態に従う。

## 圧縮の仕様(固定値・Claudeの判断)
- JPEG品質 0.6。
- 長辺が2000pxを超える画像は2000pxへ縮小。
- 再圧縮後のほうが小さい場合だけ差し替える。大きくなるなら元のまま。

## 元PDF内の画像
- 新規ファイル `file-note/compress.js` に `compressImages(doc)` を置き、`buildPdf` 内で `assemblePdf` の後に、オプション有効時だけ呼ぶ。
- 圧縮する画像(すべて満たすもの)
  - Subtype が Image、BitsPerComponent が 8
  - 色形式が DeviceRGB / DeviceGray(または成分数1・3のICCBased)
  - 圧縮形式が DCTDecode(JPEG)単体、または FlateDecode 単体(Predictorなし)
- 触らず元のまま残す画像
  - ImageMask、色キーの Mask、Decode 配列付き
  - CMYK、Indexed、白黒2値、JPEG2000、CCITT、JBIG2 など上記以外
- SMask(透過)付きの画像は本体だけ圧縮し、SMaskはそのまま残す。
- 差し替え時は Width / Height / ColorSpace / Filter / Length を更新し、DecodeParms を外す。
- 1枚で例外が出たらその画像は元のまま残し、処理を続ける。

## 追加した写真
- `export.js` の画像埋め込み時、オプション有効なら同じ品質・長辺上限で再圧縮してから埋め込む。
- 透過ありのPNGはJPEGにせず、長辺の縮小だけ行う。
- 編集データ(.filenote)内の画像は変更しない。圧縮は出力PDFにだけ効く。

## 表示
- 保存中のメッセージは既存のまま。完了メッセージも既存のまま。

## テスト
- 既存のPlaywrightテストに追加
  - 大きな画像入りPDFをチェックありで保存 → サイズが小さくなり、ページ数と文字は維持される。
  - チェックなしの保存結果は従来と同じ。
  - 対象外形式の画像を含むPDFでも保存が成功する。

## その他
- `change.md` に追加点を記載する。
- git の add / commit / push は行わない(CLAUDE.md)。
