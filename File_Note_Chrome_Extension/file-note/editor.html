PDF

PDFに、書き込もう。

文字を入力

使い方

3ステップで使えます

  1. ファイルを開くでPDFを選ぶ（画面にドラッグ＆ドロップしてもOK）
  2. 上のツールを選んで、ページに書き込む
  3. PDFを保存を押す

「PDFを保存」と「編集データを保存」の違い

PDFを保存

書き込みを入れたPDFができあがります。

  • 人に送る・印刷する・提出するときはこちら
  • 元の名前_edited.pdf で保存。元のPDFは上書きしません
  • 保存した後は、書き込みを個別に動かしたり直したりできません

編集データを保存

作業の続きをするためのファイル（.filenote）です。

  • あとで書き込みを動かす・直す・消すときはこちら
  • 「ファイルを開く」で選ぶと、保存したときの状態から再開できます
  • File Note以外のソフトでは開けません

自動保存はありません。途中でやめるときは「編集データを保存」、完成したら「PDFを保存」がおすすめです。

PDFにもとからある入力欄に書き込む

申込書・アンケートなど、PDFに入力欄（テキストボックス）が作られている場合は、その欄に直接書き込めます。

  1. 入力欄をクリック（マウスを乗せると青い枠が出ます）
  2. そのまま文字を入力。チェックボックス・選択肢・プルダウンもクリックで選べます
  3. 「PDFを保存」すると、入力した内容がPDFに残ります

どのツールを選んでいても入力できます。クリックしても青い枠が出ない欄は、見た目だけの枠です。その場合は「文字」ツールで上から書き込んでください。

ツールの使い方

選択・移動 書き込みをクリックで選択し、ドラッグで移動。何もない所をドラッグすると、まとめて選択できます
文字 置きたい所をクリック → 文字を入力 →「配置する」。置いた文字はダブルクリックで直せます
直線・矢印 始点から終点までドラッグ
手書き マウスやペンで自由に描きます
マーカー 文字の上をなぞると、半透明の線で目立たせられます
四角・楕円 ドラッグして大きさを決めます。左の「塗りつぶし」で中を塗れます
写真を追加 PNG・JPEG・WebPの画像を置きます。右下の四角をドラッグで大きさを変更
戻す・やり直す 操作を1つ前に戻す・戻した操作をやり直す

色・文字の大きさ・線の太さは、左側のパネルで変えられます。選択中の書き込みにも反映されます。

ページの操作

「選択・移動」のとき、左側にページの一覧が出ます。

開く・閉じる 一覧の左上の「‹」で閉じると、ページを広く表示できます。「›」でまた開きます
並べ替え ページの小さな画像をドラッグ
削除 ページの小さな画像をクリックして Delete キー
PDFを追加 別のPDFを後ろにつなげます
右に回転・白紙を挿入 表示中のページを回す・白いページを入れる

便利な機能

  • 画像の貼り付け：コピーした画像やスクリーンショットを Ctrl+V でページに貼れます
  • PDFをつなげる：複数のPDFをまとめて画面にドラッグ＆ドロップすると、1つにつながります
  • まっすぐ描く：直線・矢印・マーカーは Shift を押しながらで水平・垂直に。四角・楕円は正方形・正円になります
  • 細かく動かす：選択した書き込みは矢印キーで1ずつ、Shift+矢印キーで10ずつ動きます
  • 書き込みのコピー：選択して Ctrl+C → Ctrl+V
  • 表示の切り替え：右上の「表示」で「1ページずつ」と「縦に連続表示」を切り替えられます
  • 容量を小さく：「PDFを保存」の左の「画像を圧縮」にチェックを入れると、写真の多いPDFが軽くなります（文字や図形はそのまま）

ショートカット

Ctrl+S PDFを保存
Ctrl+Z 戻す
Ctrl+Y やり直す
Ctrl+C / Ctrl+V 書き込みのコピー・貼り付け、画像の貼り付け
Delete 選択した書き込み（またはページ）を削除
Esc 選択を解除

Macでは Ctrl の代わりに ⌘ を使います。

安心して使うために

  • PDFはこのパソコンの中だけで処理します。インターネット上に送られることはありません
  • パスワード付きのPDF、200MBを超えるPDFは開けません
  • もとからある文章を書き換えたり消したりはできません。上から書き込む使い方です
  • 日本語・英語のほか、記号（※ ① → ○ □ ✔ ☑ など）、絵文字、韓国語、中国語（簡体字）も書き込めます。絵文字は白黒になります。PDFで表示できない文字を入力したときは、画面の下でお知らせします
