# PDF Note — Chrome標準ビューアーをそのまま使うPDF編集拡張機能

Chromeでの通常のPDF表示は変えず、拡張機能のボタンを押したときだけ、別タブの編集画面を開きます。文字・直線・手書き・マーカー・写真を追加して、編集済みPDFをパソコンに保存できます。

Chrome標準のPDF表示画面そのものに編集ツールを重ねる機能ではありません。専用タブで編集することで、既定のビューアーをChromeのままにしています。

## v1.4.2の変更

- 「選択・移動」では、文字・画像などを選択して移動している間も、サイドバーはページ一覧だけを表示します。

## v1.4.1の変更

- サイドバーの「ページの編集」の項目を削除しました。ページの追加・移動・削除は、「選択・移動」のページサムネイル一覧で操作します。

## v1.4.0の変更

- 「パソコン内のPDFを選ぶ」を押すと、Windowsのファイル選択画面が直接開きます。選んだPDFを編集タブに読み込みます。
- 「選択・移動」では、左側にPowerPointのような番号付きページサムネイルを表示します。選択ページはオレンジ色の枠で強調します。
- サムネイルをドラッグしてページを並べ替えられます。サムネイルをクリックしてDeleteキーを押すと、そのページを削除できます。
- ページの移動・削除は「戻す」「やり直す」に対応し、書き込み・フォーム入力内容もページと一緒に保持します。

## v1.3.0の変更

- 「1ページずつ」と「縦に連続表示」を切り替えられます。連続表示では次のページを下に並べ、スクロールして各ページを編集できます。
- コピーした画像やスクリーンショットを、Ctrl+Vで表示中のページへ貼り付けられます。文字入力欄では通常の文字の貼り付けができます。
- 連続表示でも、フォーム入力・書き込み・ページの連結／移動／削除・保存に対応しています。

## v1.2.0の変更

- 別のPDFを連結できます。複数ファイルの選択と、末尾・表示中のページの前・後への追加に対応しています。
- ページを前後へ移動したり、ページ番号を指定して並べ替えたりできます。
- 表示中のページを削除できます。連結・移動・削除も「戻す」「やり直す」で取り消し・復元できます。
- ページに追加した文字・線・写真と、埋め込みフォームの入力内容を保持します。別のPDFに同名のフォームがあっても値は混ざりません。
- 編集データの形式をv2に更新しました。v1.0.0／v1.1.0の編集データも引き続き開けます。

## v1.1.0の変更

- PDFに埋め込まれた文字入力欄（AcroForm）をクリックして、その場で入力できます。日本語と複数行入力に対応しています。
- 追加する文字の初期色は `#000000`、直線・手書きの初期色は `#E15244` です。文字と線の色は別々に記憶します。
- 入力欄の内容も、PDF保存・編集データ保存・元に戻す／やり直すの対象になります。保存したPDFでも入力欄は編集可能なままです。

既存の拡張機能を更新する場合は、ZIPを展開し、現在読み込んでいる `pdf-note` フォルダー内のファイルを変更版に差し替えて、`chrome://extensions` のPDF Noteの「再読み込み」を押してください。開いている編集タブは、必要な編集データを保存してから閉じ、新しく開き直してください。

## インストール（Windows / Chrome）

1. ZIPファイルを右クリックして「すべて展開」します。
2. 展開した `pdf-note` フォルダーを、削除・移動しない場所に置きます。例：`ドキュメント\Chrome拡張\pdf-note`。
3. Chromeのアドレス欄に `chrome://extensions` を入力して開きます。
4. 右上の「デベロッパーモード」をオンにします。
5. 「パッケージ化されていない拡張機能を読み込む」を押します。
6. `manifest.json` が直接入っている **pdf-note フォルダー**を選択します。ZIPや、その外側のフォルダーを選ぶ必要はありません。
7. Chrome右上の拡張機能（パズル）ボタンから「PDF Note」をピン留めします。

インストール後に別のソフトやライブラリをインストールする必要はありません。Windowsの既定アプリやChromeのPDF設定も変更しません。

## PDFを開く

### Chromeで開いているPDFを編集する

1. 普段どおりChromeでPDFを開きます。
2. PDF Noteのアイコンを押します。
3. 「このPDFを編集」を押します。
4. 編集画面が別タブで開きます。

Web上のPDFでは、初回にそのサイトからの読み込み許可を求めます。許可は、押したPDFのサイト単位で要求します。Webページの書き換えや閲覧履歴の収集はしません。

パソコン内のPDFを、このボタンから直接読み込む場合は、`chrome://extensions` → PDF Noteの「詳細」→ **「ファイルのURLへのアクセスを許可する」**をオンにしてください。

### パソコン内のPDFを選ぶ

PDF Noteのアイコン → 「パソコン内のPDFを選ぶ」を押すと、Windowsのファイル選択画面が開きます。PDFを選ぶと、別タブの編集画面に自動で読み込みます。この方法は「ファイルのURLへのアクセスを許可する」の設定が不要です。編集画面の「PDFを開く」やドラッグ＆ドロップでも開けます。

ログインが必要なサービス、Google Driveなどのプレビュー画面、一時的な `blob:` URLでは、自動読み込みができない場合があります。その場合はPDFをダウンロードし、「PDFを開く」からそのファイルを選びます。Chromeの標準ビューアーですでに入力した内容を引き継ぐ場合も、変更を含めてダウンロードしたPDFを選んでください。

## 編集する

| ツール | 操作 |
|---|---|
| PDF内の文字入力欄 | 埋め込みフォームの入力欄を直接クリックして入力。ツールの切り替えは不要です。Tabキーでも移動できます。 |
| 文字 | 「文字」を選び、PDFの配置したい位置をクリック。日本語・英数字・改行を入力して「配置する」。 |
| 直線 | 「直線」を選び、始点から終点までドラッグ。Shiftキーで水平・垂直に固定。 |
| 手書き | 「手書き」を選び、マウスやタッチ操作で描く。 |
| マーカー | 「マーカー」を選び、線を引く。半透明で表示。 |
| 写真 | 「写真を追加」でPNG・JPEG・WebPを選択。中央に配置される。 |
| 画像の貼り付け | 画像をコピーし、「選択・移動」で貼り付け先のページをクリックしてCtrl+V。画像をページの中央に配置します。 |
| 選択・移動 | 追加した書き込みをクリックして選択し、ドラッグで移動。 |

左側で色、文字サイズ、線の太さを指定できます。追加した書き込みを選択してから値を変えると、その書き込みの設定を変更します。追加する文字の初期色は黒（`#000000`）、直線・手書き・マーカーの初期色は赤（`#E15244`）です。マーカーの初期幅は、設定した線幅または12ptの大きい方です。

PDF内の文字入力欄は、元の位置・文字サイズ・文字揃えに合わせて表示します。読み取り専用の欄は変更できません。入力した内容は、欄からフォーカスを外すと「戻す」「やり直す」の対象になります。PDFに印刷された枠や画像上の空欄は埋め込みフォームではないため、「文字」ツールで追記してください。チェックボックス・選択リストなどの既存の表示と値は保持しますが、これらを変更する機能は追加していません。

文字をダブルクリックすると、内容を編集できます。「文字を編集」ボタンでも変更できます。文字は自動折り返しをしないため、長い文章は入力時に改行してください。

写真は右下の四角をドラッグしてサイズを変更できます。通常は縦横比を保ち、Shiftキーを押しながら操作すると縦横を別々に調整できます。左側の幅・高さ入力では縦横比を保ちます。

### 表示形式を切り替える

上部の「表示」で **「1ページずつ」** または **「縦に連続表示」** を選択します。連続表示ではページを上から下に並べ、マウスホイールやスクロールバーで移動できます。表示中のページ番号がスクロール位置に合わせて変わり、クリックしたページが編集対象になります。各ページで直接フォーム入力や書き込みができます。ページ送りボタンや左側のページ選択も使えます。

### コピーした画像を貼り付ける

画像編集ソフトなどで画像をコピーするか、ブラウザーの「画像をコピー」、Windowsのスクリーンショットのコピーを使います。「選択・移動」でPDFの貼り付け先のページをクリックし、**Ctrl+V** を押します。MacではCommand+Vです。貼り付けた画像は、写真と同様に移動・サイズ変更・削除でき、「戻す」「やり直す」やPDF・編集データの保存にも対応します。

画像は1枚30MB以下で、長辺が最大2,400pxになるように縮小して取り込みます。文字入力欄・文字入力ダイアログでの貼り付けは通常の文字入力として扱います。画像のURLやHTMLだけがコピーされている場合は画像として貼り付けません。画像そのものをコピーしてください。

選択した書き込みは「選択した書き込みを削除」またはDeleteキーで削除できます。「戻す」「やり直す」も使えます。ページ送りと拡大・縮小に対応しています。

## PDFの連結・ページの並べ替え・削除

「選択・移動」では、左側のページ一覧で操作します。

1. **ページの選択**：サムネイルをクリックすると、そのページを表示します。上下矢印キーでもページを選択できます。
2. **順序の変更**：サムネイルをドラッグし、移動先に表示されるオレンジ色の挿入線の位置で放します。
3. **削除**：サムネイルをクリックして選択し、Deleteキーを押します。「戻す」で復元できます。最後の1ページは削除できません。PDF内の文字入力欄や書き込みを操作しているときは、ページ削除になりません。
4. **連結**：ページ一覧の「PDFを追加」で、別のPDFを末尾へ追加します。
5. **保存**：「PDFを保存」で、並べ替え・削除したページ構成も反映します。「編集データを保存」なら後から編集を再開できます。

文字・直線などのツールでは、左側に書き込みの設定を表示します。「選択・移動」では、書き込みを選択してもサイドバーはページ一覧のままです。文字の内容はダブルクリックで編集できます。

連結するPDFの合計サイズは200MB以下です。ページの大きさ・回転・切り抜き範囲も保持します。元のPDFファイルは上書きしません。保存したPDFでは、追加したPDFのフォーム名に識別用の接頭辞を付け、元のPDFのフォームと区別します。

## 保存する

### PDFを保存

右上の **「PDFを保存」** を押すと、`元の名前_edited.pdf` という別ファイルをダウンロードします。元のPDFは上書きしません。

保存先を毎回選びたい場合は、Chromeの「設定」→「ダウンロード」→ **「ダウンロード前に各ファイルの保存場所を確認する」**をオンにします。オフの場合は、Chromeに設定されたダウンロード先に保存されます。

元のPDFのページや文字を残し、その上に書き込みのレイヤーを追加します。追加した日本語文字も選択・検索できます。写真は長辺が最大2,400pxになるように縮小して取り込みます。

### 編集データを保存

右上の **「編集データを保存」** を押すと `.pdfnote` ファイルを保存します。使用中のPDF、ページの順序、追加した文字・線・写真の配置、埋め込み文字入力欄の入力内容が含まれます。全ページを削除したPDFは編集データに含めません。v1.0.0／v1.1.0で保存した編集データも開けます。新しい形式の編集データはv1.2.0以上で開いてください。

次回は **「編集データを開く」** からこのファイルを選ぶと、書き込みを個別に移動・編集できます。元のPDFを別途選ぶ必要はありません。

「PDFを保存」だけで保存したファイルは、今回の書き込みもPDFの内容になります。次回そのPDFを開いて追記できますが、今回の書き込みをこの拡張機能の個別オブジェクトとして移動するには、`.pdfnote` も保存してください。

編集内容の自動保存はありません。保存せずに編集タブを閉じようとすると、Chromeの確認が表示されます。

## ショートカット

| キー | 操作 |
|---|---|
| Ctrl+S | 編集済みPDFを保存 |
| Ctrl+V | コピーした画像を、編集対象のページに貼り付け |
| Ctrl+Z | 戻す |
| Ctrl+Y / Ctrl+Shift+Z | やり直す |
| Delete / Backspace | 選択した書き込みを削除 |
| Delete（ページ一覧にフォーカス） | 選択したページを削除 |
| ↑ / ↓（ページ一覧にフォーカス） | 前後のページを選択 |
| Escape | 選択を解除して「選択・移動」に戻る |

MacではCtrlの代わりにCommandを使えます。

## 対応範囲

- Chrome 130以上。最新のChromeの利用を推奨します。
- 200MB以下の、パスワードで保護されていないPDF。
- 写真は1枚30MB以下のPNG・JPEG・WebP。
- 日本語文字・通常の英数字に対応。絵文字など、同梱フォントにない文字は表示できない場合があります。
- 埋め込み文字入力欄は標準のAcroFormに対応します。XFAフォーム、PDF内のJavaScriptによる自動計算・入力検証には対応していません。
- 元からある文章の書き換え・削除、OCRには対応していません。ページ単位の追加・並べ替え・削除と、AcroForm文字入力欄の入力に対応しています。
- 保存するとPDFの内容が変わるため、元の電子署名の有効性を保つための用途には対応していません。

## プライバシー

PDFの読み込み、描画、文字・写真の追加、PDFの作成はパソコン内で行います。ファイルを外部の編集サービスへ送信しません。広告、アクセス解析、アカウント登録はありません。

Web上のPDFを開くときは、そのPDFのURLへ取得リクエストを行います。描画ライブラリ・日本語フォントはすべて同梱されており、CDNやフォント配信サイトへの通信はありません。

## ソースコード

すべてのソースコードをZIP内に含めています。

- `manifest.json`：拡張機能の設定。PDFの自動転送・標準ビューアーの置換は行いません。
- `popup.html / popup.js`：Chrome右上のアイコンから開くメニュー。
- `editor.html / editor.css / editor.js`：編集画面と操作。
- `export.js`：書き込みを元のPDFに重ねて保存する処理。
- `pages.js`：ページの連結・並べ替え・削除を保存する処理と、連結後のフォーム保持。
- `vendor / fonts`：PDF.js、pdf-lib、fontkit、日本語フォントとライセンス。

利用ライブラリとライセンスは `THIRD_PARTY.md` に記載しています。
