# File Note

Chromeで開いたPDFに、文字・線・図形・手書き・マーカー・写真を書き込んで保存できるChrome拡張機能です。

- ChromeのPDF表示はそのまま。拡張機能のボタンを押したときだけ、別タブの編集画面を開きます。
- 処理はすべてパソコン内で完結します。ファイルを外部サービスへ送信しません。広告・アクセス解析・アカウント登録もありません。
- インストール後に、別のソフトやライブラリを入れる必要はありません。

現在のバージョン：**v1.7.0**（対応ブラウザー：Chrome 130以上）

## インストールせずに使う（Web版）

<https://file-note.r725cf.workers.dev> を開くだけで、同じ編集機能を使えます。

- 拡張機能のインストールは不要です。
- 処理はブラウザー内で完結します。PDFがサーバーへ送られることはありません。
- Chromeで表示中のPDFを「このPDFを編集」で開く機能は、拡張機能版だけです。Web版では、PDFをダウンロードしてから「ファイルを選ぶ」で開いてください。

以下は拡張機能版の手順です。

---

## 1. ダウンロード

1. このリポジトリのページ（<https://github.com/A-ryo725/File_Note>）を開きます。
2. 緑色の **「Code」** ボタン → **「Download ZIP」** を押します。
3. ダウンロードした `File_Note-main.zip` を右クリックして **「すべて展開」** します。

展開したフォルダーの中の、次のフォルダーが拡張機能本体です。

```
File_Note-main/
└─ File_Note_Chrome_Extension/
   └─ file-note/        ← これを使います（manifest.json が直接入っているフォルダー）
```

`file-note` フォルダーは、削除・移動しない場所に置いてください（例：`ドキュメント\Chrome拡張\file-note`）。Chromeはこのフォルダーを直接読み込むため、移動や削除をすると拡張機能が使えなくなります。

## 2. インストール（Chrome）

1. Chromeのアドレス欄に `chrome://extensions` と入力して開きます。
2. 右上の **「デベロッパーモード」** をオンにします。
3. **「パッケージ化されていない拡張機能を読み込む」** を押します。
4. `file-note` フォルダーを選択します（ZIPファイルや、その外側のフォルダーではありません）。
5. Chrome右上の拡張機能（パズルの形）ボタンから **「File Note」** をピン留めすると、すぐ使えて便利です。

### 任意の設定

- **Chromeで開いたパソコン内のPDFを、そのまま編集したい場合**
  `chrome://extensions` → File Noteの **「詳細」** → **「ファイルのURLへのアクセスを許可する」** をオンにします。
  （「パソコン内のファイルを選ぶ」から開く場合は不要です）
- **保存先を毎回選びたい場合**
  Chromeの「設定」→「ダウンロード」→ **「ダウンロード前に各ファイルの保存場所を確認する」** をオンにします。

## 3. ファイルを開く

| 開き方 | 手順 |
|---|---|
| Chromeで表示中のPDFを編集 | PDFを開いた状態で File Noteのアイコン → **「このPDFを編集」** |
| パソコン内のファイルを選ぶ | File Noteのアイコン → **「パソコン内のファイルを選ぶ」** |
| 編集画面から開く | 編集画面の **「ファイルを開く」**、またはファイルをドラッグ＆ドロップ |

- Web上のPDFは、初回だけそのサイトからの読み込み許可を求められます。
- ログインが必要なサイトやGoogle Driveのプレビューなどでは自動で読み込めない場合があります。その場合はPDFをダウンロードしてから「ファイルを開く」で選んでください。
- 編集データ（`.filenote`）も、上のどの方法でも開けます。

## 4. 編集する

編集画面右上の **「使い方」** を押すと、操作方法をいつでも確認できます。

上部のツールを選んで、ページ上で操作します。

| ツール | 使い方 |
|---|---|
| 選択・移動 | 書き込みをクリックして選択し、ドラッグで移動。矢印キーでも移動できます |
| 文字 | 置きたい位置をクリック → 文字を入力 →「配置する」。ダブルクリックで再編集 |
| 直線・矢印 | 始点から終点までドラッグ（Shiftで水平・垂直に固定） |
| 四角・楕円 | ドラッグして大きさを決めます |
| 手書き | マウスやタッチで自由に描きます |
| マーカー | 半透明の線を引きます |
| 写真を追加 | PNG・JPEG・WebPを選んで配置。右下の四角をドラッグでサイズ変更 |
| PDF内の入力欄 | PDFに埋め込まれた入力欄・チェックボックス・プルダウンは、直接クリックして入力できます |

- 左側のパネルで、色・文字サイズ・線の太さを変更できます。
- コピーした画像やスクリーンショットは **Ctrl+V** でページに貼り付けられます。
- 「戻す」「やり直す」で操作を取り消し・復元できます。
- 上部の「表示」で「1ページずつ」と「縦に連続表示」を切り替えられます。

### ページの操作（「選択・移動」の左側のページ一覧）

- **一覧の開閉**：一覧の左上の「‹」で閉じるとページを広く表示できます。「›」でまた開きます
- **並べ替え**：サムネイルをドラッグ
- **削除**：サムネイルを選んで Delete キー
- **PDFの連結**：「PDFを追加」で別のPDFを末尾に追加（複数のPDFをドラッグ＆ドロップしても連結できます）
- **回転・白紙ページ**：「右に回転」「白紙を挿入」

## 5. 保存する

| ボタン | 保存されるもの |
|---|---|
| **PDFを保存** | `元の名前_edited.pdf` として書き込み済みのPDFをダウンロード。元のPDFは上書きしません |
| **編集データを保存** | `.filenote` ファイル。次回「ファイルを開く」などで選ぶと、書き込みを個別に移動・修正できます |

- 容量を小さくしたいときは、「PDFを保存」の左の **「画像を圧縮」** にチェックを入れてから保存します（画像だけを圧縮し、文字や図形はそのまま残ります）。
- **自動保存はありません。** 作業を続けたい場合は「編集データを保存」もしておくと安心です。

## 6. ショートカット

| キー | 操作 |
|---|---|
| Ctrl+S | PDFを保存 |
| Ctrl+Z | 戻す |
| Ctrl+Y / Ctrl+Shift+Z | やり直す |
| Ctrl+C / Ctrl+V | 書き込みのコピー・貼り付け、画像の貼り付け |
| Delete / Backspace | 選択した書き込み（またはページ）を削除 |
| Escape | 選択を解除 |

MacではCtrlの代わりにCommandを使います。

## 7. 更新するとき

1. 新しいZIPをダウンロードして展開します。
2. 今使っている `file-note` フォルダーの中身を、新しい `file-note` フォルダーの中身に置き換えます。
3. `chrome://extensions` で File Noteの **「再読み込み」**（丸い矢印）を押します。
4. 開いている編集タブは、必要なら編集データを保存してから閉じ、開き直してください。

> **v1.6.0以前（旧名「PDF Note」）から更新する場合**：フォルダー名が `pdf-note` から `file-note` に変わったため、古い拡張機能を削除してから `file-note` を読み込み直してください。「ファイルのURLへのアクセスを許可する」などの設定はもう一度必要です。旧形式の編集データ（`.pdfnote`）は開けません。

## 8. 対応範囲と注意

- 200MB以下の、パスワードで保護されていないPDFに対応しています。
- 元からある文章の書き換え・削除、OCRには対応していません。
- 書き込める文字：日本語・英語のほか、記号（※ ① → ○ □ ✔ ☑ など）、絵文字（白黒）、韓国語、中国語（簡体字）。PDFで表示できない文字を入力すると、画面の下でお知らせします。
- XFAフォームや、PDF内のJavaScriptによる自動計算には対応していません。
- 保存するとPDFの内容が変わるため、電子署名の有効性は保たれません。
