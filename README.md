# File_Note

## インストール（Windows / Chrome）

1. ZIPファイルを右クリックして「すべて展開」します。
2. 展開した `file-note` フォルダーを、削除・移動しない場所に置きます。例：`ドキュメント\Chrome拡張\file-note`。
3. Chromeのアドレス欄に `chrome://extensions` を入力して開きます。
4. 右上の「デベロッパーモード」をオンにします。
5. 「パッケージ化されていない拡張機能を読み込む」を押します。
6. `manifest.json` が直接入っている **file-note フォルダー**を選択します。ZIPや、その外側のフォルダーを選ぶ必要はありません。
